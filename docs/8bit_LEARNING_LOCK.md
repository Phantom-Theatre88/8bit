## 「電気を見える化｜V・W・Aの法則」の入口 LOCK（2026-10-09）

最初に、次の説明を表示する。

- W（ワット）＝電力：灯体などが、どれくらい電気を使うかを表します。
- V（ボルト）＝電圧：電気を流そうとする「押す力」にたとえられます。
- A（アンペア）＝電流：回路を流れる電気の量を表します。

その説明を読める位置に置いた上で、「何を求めたい？」と問いかける。

選択肢は「電力（W）」「電圧（V）」「電流（A）」とする。説明より先に選択を要求しない。

### 表記と説明の注意

- 入口では、機器の表示で目にする W・V・A を前面に出す。
- W・V・A は単位であり、物理量の記号 P・V・I とは区別する。式で P・V・I を使う場合は、何を表す記号か説明する。
- 電圧の「押す力」は理解のためのたとえであり、物理的な力そのものという説明にしない。
- 電流の「電気の量」は導入用の表現とする。詳しく説明するときは、単位時間あたりに流れる電荷の量であることを補う。
- 定義を置くだけで終わらず、実際の灯体や電源の表示と結び付け、選択に必要な意味を伝える。

## 改修時の確認

- 未説明の専門用語や記号から始めていないか。
- 用語の意味を知らなくても、説明を読んで次の操作を選べるか。
- 「何を求めたい？」より前に、選択肢の意味を説明しているか。
- 文字・背景色・区分が、説明の読みやすさと学ぶ順番を支えているか。

## 「電気って波なの？」の範囲 LOCK（2026-10-10）

- 最初の目的は「交流の電圧が時間とともに変わる」ことを知ること。山・谷・0 → 1回の波（1周期） → Hz → 日本の50/60Hz → 機器への影響の順で説明する。
- 初期画面は1本の波。比較を選んだ時だけ50Hzと60Hzを同じ時間幅・同じ電圧尺度で上下に表示する。角度目盛りや複数方式を入口へ並べない。
- 単相3線の100/200V比較、三相3線、位相制御の操作はこのページでは扱わない。各テーマの教材で説明する。調光とのつながりは最後の短い案内に留める。
- 日本では東京50Hz・大阪60Hzを具体例にする。昔の一部の電源同期時計や、電源周波数で回転速度が決まるテープレコーダーの切り替え・調整を説明する。すべての時計・録音機に当てはまる説明にしない。
- ステッピングモーターの角度が電源50/60Hzだけで変わるとは書かない。制御信号の数・速さと電源周波数を区別する。
- 波の谷は電圧がない状態ではなく逆向き。
- このページでは141V・実効値の説明を扱わない。縦軸と交点の表示は、電圧の向き・山・0・谷を伝えるものとし、瞬間の電圧数値を覚えさせない。
- 数値の桁や符号が変わっても結果欄が折り返したり、下の操作欄が動いたりしない。名称と数値を固定行へ分け、数値を右揃えにする。
- 波形ページの説明・操作は16px以上を基本とし、重複説明を整理して読みやすさを保つ。先生は背景透過の素材で、横画面では幅100px以上を確保し、案内はその時に見る場所へ絞る。

## 「8-bit 調光卓」の入口 LOCK（2026-10-10）

- iPad横画面を基準に「①フェーダーを動かす → ②アナログとデジタルを比べる → ③灯りを見る」を同時に見渡せる配置とする。
- 中央の主目的は、同じフェーダー位置で、アナログ側の出力電圧（V）・波形と、デジタル側のDMX値・8-bit表示を見比べること。DMXから交流波形へ進む一方向の説明に置き換えない。入口は白熱灯の調光を例にする。
- アナログ側では0〜100V、デジタル側では0〜255の数字の指示を表示する。DMXは電圧ではない。これは表示と制御の違いを学ぶ比較であり、DMXで制御する調光器にも灯体への電圧出力がある。
- 百分率は「フェーダー位置」と表記する。見た目の明るさの測定値として扱わない。DMX値を電源電圧として説明しない。
- 波形は山・谷・0を含む。元の電源を破線、灯体へ通す部分を橙色、通し始めを大きな赤い点で示す。Hzの説明を重複させず、波・カーブ・8-bitの中身を切り替えて見る。
- 8-bitは8個の0／1で0〜255の256段階。各桁の重みと、1の桁を足した現在値を結び付ける。
- カーブと灯りは教材用の簡略例と明示する。規格の確認が済んでいない数式をJATET規格として表示しない。旧「B＝2.7乗」表示と0.6乗計算の不一致を持ち越さない。
- 本文・操作・図のラベルは16px以上を基本に、チャコール背景・明確な区分・背景透過の先生を使用する。横画面で収まりと連動を確認し、縦画面は並べ替えてスクロールできるようにする。

## テーマ「調光」第1ページ｜設計LOCK（2026-11-04）

### 決定事項と正式タイトル

- 正式タイトルは **「調光とは？ ― 光の明るさが、舞台を変える。」** とする。タイトルも含めて採用・LOCK。
- 本ページの主題は水抵抗器の歴史や操作ではなく、**舞台照明にとって調光がなぜ重要なのか**を伝えること。
- 明るさを変えることで、同じ舞台でも時間・空間・感情・観客が受け取る印象を変えられることを最初に視覚的に見せる。「調光とは光の強さを変え、物語を表現する技術」であることを入口に据える。
- 冒頭のメイン表現は、**同じ舞台・同じ条件で明るい状態と暗い状態を比較する**ものとし、単なる調光器の操作説明にしない。
- 先生のひとことは、光の明るさの変化が舞台表現を変えることを伝え、その後に「その明るさをどうやって変えるのか？」と原理の説明へつなぐ。

### 原理説明に使用する水抵抗器（補助図解）

- 水抵抗器は「調光の仕組み」の理解を支える**具体例**として置く。歴史上の古い技術という紹介を主目的としない。
- 中央に**塩水の入ったビーカーと2枚の銅板（電極）**を描き、**左の銅板のみを上下させる**。右の銅板は固定、電極間の距離は一定。
- 左の電極を深く浸すと水中に接する面積が増えて電気が流れやすくなり、浅くすると流れにくくなるという基本的な関係を図解する。実際の特性を厳密な比例関係として示さない。
- 回路接続は **「交流電源 → 左の可動電極 → 塩水 → 右の固定電極 → 白熱電球 → 電源へ戻る」** という**直列回路**とし、塩水の抵抗経路をバイパスして電源から電球へ直接つなぐ誤配線は禁止する。
- 図は教育用の概念図であり、実物の組立・通電を促す説明としない。演出用の明るさ表現は概念的表示とし、現実の光量との厳密な比例を示唆しない。
- 電球のイラストは既存教材の **`assets/Light.webp`** を再利用する。新しい別デザインの電球に置き換えない。
- 操作・ドラッグは理解を助ける補助機能として残してよいが、ページの視覚的な主役にしない。

- 第1ページの次は、オートトランス式（交流電圧の振幅を変える）・サイリスタ式（SCRによる位相制御）などの調光原理、さらにアナログ0〜10V制御とDMXなどのデジタル制御へとつなぐ。

### 水抵抗式調光の操作機構｜追加LOCK（2026-11-04）

- 第1ページの操作部は**縦型フェーダー（操作レバー）と銅板を、ワイヤー・固定滑車で機械的に結ぶ表現**を採用する。フェーダーを**上げると左の可動銅板が下がり**、塩水に浸かる電極面積が増え、電球が**明るくなる**。フェーダーを下げると逆に銅板が上がり暗くなる。横フェーダー操作で上下を表す方式は採用しない。
- ワイヤーは滑車を介し、両端が逆向きに動く**つるべ型の機械的連動**として見せる。**操作用ワイヤーと通電用の電気配線を形・色で区別**し、ワイヤー自体を回路に混ぜない。
- 左の銅板の**大きさは一定**で、上下位置と浸かる面積のみ変化する。右電極・水面・電極間距離は固定。電球は既存の `assets/Light.webp` と既存調光教材の発光表現を活かす。
- 歴史的根拠：国立科学博物館の『舞台照明用調光装置の系統化調査』に記された大阪朝日会館（1926年開館）の、ドラム・ワイヤー・滑車による電極操作機構の記録を参照する。ただし**当時の装置そのものが現代的な縦型フェーダーだったとは説明しない**。本ページのフェーダーと単一滑車は、新人向けに原理を分かりやすくした模式表現。
