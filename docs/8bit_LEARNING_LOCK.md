# 8bit 教材共通の聖典（設計原則）LOCK

## 対象者の大前提 LOCK（2026-10-09）

- この教材は、電気の知識がない人に向けて作る。
- 「電力って？ 電圧って？ 電流って？」という状態を出発点とする。用語・記号・単位・計算方法を知っている前提で説明やUIを組み立てない。
- 利用者は、自分が何を求めたいのか、どの項目を選べばよいのかも、まだ分からないことがある。
- 作成・改修・レビューのたびに、この前提を確認する。専門家にとって分かるかではなく、初めて触れる人が理解して選べるかを判断基準とする。
- この原則は、電気教材だけでなく、8bit全体の説明・設問・操作案内に適用する。各分野の専門知識を入口の前提にしない。

## 「電気を見える化｜V・W・Aの法則」の入口 LOCK（2026-10-09）

最初に、次の説明を表示する。

- W（ワット）＝電力：灯体などが、どれくらい電気を使うかを表します。
- V（ボルト）＝電圧：電気を流そうとする「押す力」にたとえられます。
- A（アンペア）＝電流：回路を流れる電気の量を表します。

その説明を読める位置に置いた上で、「何を求めたい？」と問いかける。

選択肢は「電力（W）」「電圧（V）」「電流（A）」とする。説明より先に選択を要求しない。

### 表記と説明の注意

- 入口では、機器の表示で目にする W・V・A を前面に出す。
- W・V・A は単位であり、物理量の記号 P・V・I とは区別する。式で P・V・I を使う場合は、何を表す記号か説明する。
- 電圧の「押す力」は理解のためのたとえであり、物理的な力そのものという説明にしない。
- 電流の「電気の量」は導入用の表現とする。詳しく説明するときは、単位時間あたりに流れる電荷の量であることを補う。
- 定義を置くだけで終わらず、実際の灯体や電源の表示と結び付け、選択に必要な意味を伝える。

## 改修時の確認

- 未説明の専門用語や記号から始めていないか。
- 用語の意味を知らなくても、説明を読んで次の操作を選べるか。
- 「何を求めたい？」より前に、選択肢の意味を説明しているか。
- 文字・背景色・区分が、説明の読みやすさと学ぶ順番を支えているか。

## 画面設計の基準 LOCK（2026-10-09）

- 縦・横の両方に対応するが、設計の基準はiPad横画面とする。
- 「電気を見える化」では、読みやすい文字サイズを保ち、用語説明・選択・入力・計算結果・解説をiPad横の1画面に収めることを完成条件とする。
- 高さは端末全体ではなく、ブラウザの操作部を除いた表示領域を基準にする。
- 収めるために説明を隠したり、文字を極端に小さくしたりしない。重複表示と不要な余白を整理する。
- 縦画面では、同じ内容を画面幅に合わせて並べ替え、必要に応じて縦スクロールできるようにする。
- 横画面の収まり・縦画面の読みやすさ・計算動作を確認してから完成とする。
