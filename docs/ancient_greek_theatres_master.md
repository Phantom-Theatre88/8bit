# 古代ギリシャ文化圏・劇場マスター

## 位置付け
- 目的：History「古代ギリシャ劇場」親カードの母集団を作る。
- 方針：「確認できた古代劇場をできるだけ網羅」する。
- この一覧は完成版ではない。史料確認しながら段階的に追加する。
- ギリシャ期・ヘレニズム期・ローマ期の改築を同一時点の情報として混同しない。
- 「全て網羅」とは表記しない。

## 管理項目
各劇場について、名称／地域／年代／文化期／遺構状況／改築履歴／写真・図面／劇場史・照明史上の確認ポイント／出典／確度を保持する。

## History表示への暫定方針
- メインタイムライン：親カード「古代ギリシャ劇場」1枚。
- 詳細：確認済み劇場を小カード／一覧で巡る。
- 小カードは名称、時代／地域、写真から確認できる構造上の特徴を基本にする。
- 地域・年代・改築フェーズをフィルタ／分類候補として保持する。
- 代表劇場は調査後に選定する。知名度だけで固定しない。
