# LOCK｜調光テーマ「調光とは」「操作とは」再編（2026-11-07）

## 最上位目的
照明家の視点から、光を変える調光機構と、照明家がそれを操る操作技術を区別して学ぶ。説明重複を減らし、既存教材とテスト版の成果を維持する。

## 「調光とは」側（主担当）
- 水抵抗式
- 変圧器式：1934年と1961年を**同一方式の中の2年代**として扱う。現行 `DimmingControlHistoryTest.html` の1934年・1961年テスト成果を統合対象とする。1934年はワイヤによる機械的直接操作、1961年は電動による遠隔操作（弱電制御）への進展を説明。1961年をサイリスタ式と混同しない。
- スライダック（単巻変圧器）
- サイリスタ
- PWM

※方式の歴史的正式名称・年号・個別装置の仕様は一次資料と照合し、未確認事項を事実として固定しない。
※スライダックの先生コメントは、同容量の複巻変圧器に比べて比較的小型にでき、移動式調光装置としても使われた趣旨。

## 「操作とは」側（簡潔な参照説明）
- 直接操作：調光とは側で学んだ水抵抗式、ワイヤ機械操作の1934年式、スライダックなどを例に、操作が調光機構へ直接伝わることを説明する。
- 強電操作：DimPac等の**調光器一体型の強電操作卓**を紹介。単に「可搬型調光器」と説明しない。
- 弱電操作：1961年の電動遠隔操作、1963年SCR等を参照し、制御信号で離れた調光器へ指示することを説明。
- デジタル8bit：1980〜90年代のDMX512登場・普及との関係を紹介。
- デジタル16bit：ムービングライトの精密な制御との関係を紹介。2000年以降を「初登場年」と断定しない。

## UI／制作LOCK
- 「操作とは」で水抵抗・変圧器・スライダック・サイリスタ等の内部機構を再説明せず、「調光とは」への参照・リンクでつなぐ。
- 1934年・1961年のテスト版を「操作とは」の独立ページとして再配置しない。
- 既存完成教材・共通ヘッダー・キャラ設定・画像素材・操作機能を保持する。
- この文書は構成LOCKであり、完成ページの実装・画面検証を意味しない。完成イメージは別途検討してから実装する。


## 追加LOCK｜「制御とは」のフェーダー中心設計（2026-11-07）

### 教材の核
**フェーダーを中心に、方式によってフェーダーが何を扱うかを、実際に動かして理解する。**
操作は1画面内のタブ切替で、1タブにつき1項目を表示する。完成済みのデジタル8bit／16bit教材は**実装・操作機能をそのまま内包**する（概要だけのリンクに置き換えない）。

| タブ | 新人にまず伝えること |
| --- | --- |
| 直接制御 | フェーダーの動きをワイヤ等で機械的に伝える。水抵抗式・1934年変圧器式・スライダック等の詳細は前の「調光とは」を参照し、ここで機構を再描画しない。 |
| 強電制御 | フェーダーにAC100Vの電気が流れる、という操作感覚を見せる。教材の簡略概念図は「100Vコンセント → フェーダー → 電球」。フェーダーを動かすと電球の明るさが連動する。強電操作卓DimPacを例示する。 |
| 弱電制御（間接制御） | フェーダーがDC0〜10Vの制御電圧を扱う、という違いを見せる。遠隔の調光器に指示する。1961年電動遠隔操作・1963年SCR等の歴史を短く紹介。 |
| デジタル8bit | フェーダー位置をデジタル値0〜255として扱う。完成済み教材をそのまま内包。 |
| デジタル16bit | 2バイトで0〜65,535の細かな値を扱う。完成済み教材をそのまま内包。 |

### 表現と設計条件
- **「操作入力 → 何が伝わるか → 電球／灯具の変化」**を体験する。回路内部の技術解説はこのページでは不要。
- フェーダーの**二重表示は禁止**。1つの実操作部だけで結果が連動する。
- 強電と弱電は**フェーダーが扱う電気（AC100V対DC0〜10V）**を主役に対比し、余分な架空機器・歴史年号・配線を描かない。
- 電子回路として全機種を一般化するのではなく、照明家向けに代表例を単純化した概念説明とする。安全面では商用電源を実物の教材配線として組ませない。
- 現行GitHubの共通ヘッダー・スタイル・先生素材と既存教材のレイアウトを採用する。旧デザイン・旧名称を復活させない。
- 変更範囲は「制御とは」の不足部分と必要な「調光とは」への参照のみ。既存完成済み画面には不要な変更をしない。
- このLOCKは設計方針の確定であり、完成ページの実装・動作検証を意味しない。
