## 最上位原則
- iPad横画面を主対象とする。
- 既存の8bit照明史ページの時代タイムライン、歴史カード、時代別背景、下部詳細情報の資産を活用する。
- 時代を切り替えても操作UIは安定させ、時代・テーマ・カードを段階的に選ぶ。テーマ切替はページ遷移しない。
- 歴史的事実は資料と照合し、画像の権利・出典・年代を確認する。

## LOCK：画面配置・操作
1. 上部：既存の**時代タイムラインをそのまま使う**。時代切替で対象データと右側背景を更新。
2. 中央左：既存8bitトップのTHEME SELECTOR方式を応用した9テーマの縦型選択欄。狭い幅でも読める横長ボタンとし、約6件が見える高さを目安に**独立縦スクロール**。全9件はスクロールで選択でき、選択中のテーマを強調する。
3. 中央右：選択テーマに属する既存デザインの**歴史カードを自由配置**する領域。左のテーマを変えるとカード群が切り替わる。
4. 下部：最初から表示する**高さ固定の情報パネル**。初期時は案内・時代やテーマの説明、歴史カード選択後は概要へ切り替え。開閉で中央領域を押し潰さない。
5. 詳細表示の3段階：**下部固定パネル＝概要、フロート＝詳細、全画面＝精読**。長文や資料はフロート内スクロール／全画面で閲覧し、閉じれば元の選択状態に戻る。
6. 初期画面には下部パネル内の説明コンテンツを用意する。独立した説明ページは必須ではない。
7. 下部パネルに先生キャラクターの一口解説を継承する。
8. テーマボードの初期一覧と、テーマ選択後のセレクター＋歴史カード表示は別の表示状態として扱う。表示配分は詳細表示時も破綻しないことを優先する。

## LOCK：背景・テーマ画像の責務分担
- **中央左のテーマセレクター：全時代共通の背景・意匠**。ただし9テーマごとに固有の識別画像／色／アイコンを用いる。時代切替でテーマボタンの背景は変更しない。
- **中央右の歴史カードエリア：時代ごとに象徴的な劇場写真を背景として採用**。時代切替に連動し、同一時代のテーマ切替では変更しない。既存古代背景は活用候補。
- 写真はカードの文字を妨げない程度に暗色オーバーレイをかける。背景写真は歴史資料として出典・撮影者・ライセンスを確認し、クレジットを表示する。
- 古代／中世／近世／近代／現代それぞれの象徴的劇場写真は**候補の調査と検証を経て確定**。中世の上演空間は現存劇場写真だけで表現できない可能性があるため、根拠ある復元資料等も検討する。
- これまで制作した立体テーマ画像は小アイコンに無理に縮小せず、横長セレクター背景等への活用を検証する。
