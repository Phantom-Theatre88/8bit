# 舞台照明史（History）実装方針 LOCK

## 目的
8bit「舞台照明インタラクティブ図鑑」に、アナログ時代から現代のネットワーク照明までを連続して学べる「照明史」を独立カテゴリーとして追加する。

## 入口
- 表示名：照明史
- 内部名：history
- 既存の「電気 / 調光 / 信号 / Network / 灯具 / シュート」と並ぶ独立カテゴリーとする。

## ゴールUI
- iPad横画面を前提とする。
- GitHub現行版の8bit照明図鑑UIをデザイン基準とする。
- 「8bit」は教材名であり、ピクセルアート化しない。
- 画面は上下2段構成だが、固定50:50にはしない。
- 通常時は上段のタイムラインを大きく表示し、複数レーンを俯瞰できる。下段は先生＋選択項目の概要をコンパクト表示する。
- 項目選択時は上段を縮め、下段がせり上がって詳細情報を広く表示する。
- 上段：紀元前〜現代までを1本につないだ横スクロール式タイムライン。
- 下段：選択した技術の詳細情報。
- 下段右端：既存の先生キャラクターを基本1種類で常駐表示。
- 既存のキャッチ／アイコン体系を使用する。

## タイムライン操作
- 指で横スワイプできる。
- 年代をタップすると該当年代へジャンプする。
- 技術項目を選択すると、その項目が自動的に中央へ移動する。
- ページ遷移せず、選択に応じて下段の内容だけを切り替える。
- 年代位置は完全比例ではなく、技術が密集する年代の可読性を確保したセミスケール型とする。

## 詳細表示
選択項目ごとに必要に応じて以下を表示する。
- 技術名・年代
- 何なのか？
- なぜ必要だった？
- 何が変わった？
- Before / After
- 先生のひとこと
- 関連する既存8bit教材・シミュレータへのリンク
- 関連教材が存在しない場合はリンクを無理に表示しない。
- 参照可能な項目では「実物写真」「原資料」「動画」「既存8bitシミュレータ」を詳細欄から参照できる構成を検討する。

## 歴史の範囲 LOCK
PowerPointで整理した「アナログ〜DMX誕生」と「DMX〜ネットワーク時代」を一部の基礎データとしつつ、History全体は舞台照明そのものの歴史へ拡張する。

- 起点は古代の自然光（太陽光）まで遡る。
- 国立科学博物館の2024年「舞台照明用調光装置の系統化調査」は、古代ギリシャの紀元前5世紀頃の劇場を太陽光による舞台照明の時代として整理している。
- 人工光源は、油灯・ろうそく → 石油ランプ → ガス灯 → 白熱電球 → 放電灯・ハロゲン等 → LED → レーザー等の変化を追う。
- 光源だけでなく、色・光学・灯具・出力制御・操作/記憶・信号/規格・Network・伝送媒体が相互に影響しながら進化した歴史として扱う。
- 2026年の国立科学博物館「舞台照明器具技術の系統化調査」を、灯具・光学・白熱/ハロゲン・プロファイル/フォロー・LED化の重要な基礎資料として追加する。

## 年代表記ルール LOCK
歴史上の出来事を無理に単一年へ固定しない。

- 規格制定日など一次資料で年を確定できるもの：確定年「●」で表示する。
- 製品の開発・発表・発売・初設置などが確認できるもの：年と「開発」「発表」「設置」等の意味を併記する。
- 開発・設置・利用・普及の境界が曖昧なもの：1970年代後半、1990年代、2000年代中盤など年代帯「━━」で表示する。
- 普及時期しか確認できないもの：「○○年代に普及」とし、誕生年とは区別する。
- 資料間で年が食い違う場合：どちらかへ勝手に統一せず、差異を注記する。
- Art-Net II、AMX192 / D54、ETCNet1、Net3等は、根拠なく一点の誕生年を設定しない。
- 教材の目的は年号暗記ではなく「いつ頃、何が変わったのか」を理解すること。

## タイムラインの技術レーン LOCK
Historyのマスターデータは以下の技術軸で整理する。

- 光源

- 光学
- 灯具
- 出力制御
- 操作・記憶

製品年表ではなく、各技術が「なぜ必要になり、何を変えたか」を背骨にする。

## 一次資料調査で確定・採用する主要項目
- 紀元前5世紀頃：古代ギリシャ劇場。自然光（太陽光）による舞台照明（年代帯）
- 16世紀末〜17世紀初頭：イタリアの劇場で油灯・ろうそく（年代帯）
- 19世紀：石油ランプ → ガス灯 → 白熱電球（年代帯）
- 1911：帝国劇場・電気式舞台照明
- 1924/1925：国産抵抗式調光器。丸茂公式社史と科博資料に1年差があるため両方を保持する。
- 1934：多分岐式調光変圧器
- 1961：サイリスタ調光
- 1963：劇場へのサイリスタ導入
- 1966〜：サイリスタ普及
- 1969：メモリ調光操作卓
- 1970年代：メモリ調光の発展
- 1974：ユニレールディマー
- 1977〜1978：MALIAC-8。開発と実設置を区別する。
- 1978：ユニファイル
- 1981：μファイル
- 1984〜1986：マリオネット
- 1986：DMX512
- 1990：DMX512/1990
- 1991〜1995：JATET-L-3010への流れ
- 1995：JATET-L-3010「照明等演出用設備の伝送規格」
- 1990年代：ETCNet1（年代帯）
- 1997：ETCNet2。ETC公式資料でObsession IIへの初導入を確認（導入年として確定）
- 1998〜：Art-Net I
- 2004：DMX512-A
- 2006：RDM / ACN
- 2000年代：Art-Net II（世代として扱い単一年に固定しない）
- 2000年代後半：Net3（移行期として扱い単一年に固定しない）
- 2009：sACN / E1.31
- 2010年代〜：Multicast + IGMP（運用変化）
- 2010年代〜現在：Ethernet → Fiber → Single Mode（舞台照明ネットワークの物理基盤の変化）

## JATET-L-3010の位置づけ LOCK
- L-3010は調光卓の型式ではなく、JATETの「照明等演出用設備の伝送規格」。
- 1995年の規格として扱う。
- DMX512の単純な「日本版」として説明しない。
- 舞台・スタジオの照明器具、装置、各種システム間の制御信号方式を共通化し、相互互換性を確保する国内規格の流れとして扱う。
- DMX512から枝分かれする国内設備側の流れとしてタイムライン表現を検討する。
- 現行機材資料にもDMX512信号とL-3010信号の併記例があるため、単なる過去の規格として扱わない。

## ファクトチェック運用 LOCK
- Historyに追加する年代・技術・製品・規格は、実装前に必ず根拠資料を確認する。
- 一次資料を最優先し、メーカー公式資料、規格団体公式資料、公的な技術史調査を優先する。
- 二次資料しかない場合は、その旨を記録し、確定年として扱わない。
- 開発年、発表年、発売年、初設置年、利用開始、普及期を混同しない。
- 年代が確定できないこと自体を欠点とせず、年代帯として正確に表示する。
- 写真・動画は「存在する」ことと「8bit内へ転載できる」ことを分けて確認する。転載条件が不明な場合は原資料へのリンクを基本とする。
- 各項目には、参照元URL/資料名・確認内容・確度をマスターデータとして保持する。

## 現時点で追加確認できた資料
- 国立科学博物館 2024調査：舞台照明史は古代ギリシャ時代まで遡り、紀元前5世紀頃の劇場では太陽光。16世紀末〜17世紀初頭のイタリアで油灯・ろうそくが人工光源として使用されたことを確認。
- 国立科学博物館 2026調査：白熱電球期の器具、戦後のハロゲン電球、1980年代以降のプロファイル/フォロースポットの光学高度化、2000年代以降のLED化を舞台照明器具の構造的転換として整理。
- ETC公式：ETCNet2は1997年にObsession IIで初導入。
- ESTA公式：DMX512-1986、DMX512/1990、ANSI E1.31-2009の規格年を確認。
- Artistic Licence公式：Art-Net 3は2011年、Art-Net 4は2016年9月リリースを確認。


## タイムライン表示密度 LOCK
- 横方向の時間軸も、縦方向の9技術レーンも等間隔・等分割にはしない。
- 横方向はセミスケール型とし、出来事の少ない時代は圧縮、技術変化が密集する時代は広く表示する。
- 縦方向も情報量に応じてレーンの高さを変えてよい。情報が少ないレーンは細く表示できる。
- 9レーンの上下の並び順は固定し、利用者が位置を見失わないようにする。
- 寸法を動的に変える場合は急激な伸縮を避け、視認性と操作の安定を優先する。
- History画面は均等なグリッドではなく、その時代の情報密度に合わせた地図として設計する。
- 通常時は複数レーンの俯瞰を優先し、項目選択時は詳細欄をせり上げて情報領域を確保する。


## 先生のひとこと運用 LOCK
- WHAT / WHY / CHANGE は、確認できた史実・技術情報を記載する。
- 本筋から少し外れる舞台史の話や伝承的な説明は「先生のひとこと」に分離できる。
- 出典を確認できていない内容は、本文の確定事実として扱わず、断定しない表現にする。
- 後から根拠資料を確認できた場合は出典を追加し、必要に応じて表現を更新する。

## 太陽光｜先生のひとこと LOCK
「悲劇などは上演順によって夕方になり、最後は日没の頃まで上演された、という話もあるよ。自然光そのものが舞台の変化になっていたんだね。」


## History構造更新 LOCK：劇場・舞台環境
- 既存9技術レーンに加え、「劇場・舞台環境」のLINEを追加する。
- 劇場・舞台環境は単なる背景情報ではなく、照明技術の進化を要求・制約する主要因として扱う。
- 「環境が変わる → 必要な光が変わる → 光源・色・光学・灯具・出力制御・操作・信号・Network・伝送媒体が変化する」という因果関係をHistoryで見せる。
- 劇場・舞台環境LINEと各技術レーンの出来事は、必要に応じて関連付けて表示する。
- 例：野外劇場と自然光、屋内化と人工光源、劇場大型化と集中/遠隔制御、現代の大規模設備とNetwork/Fiber。
- 技術9レーンと劇場・舞台環境LINEは、横・縦とも等間隔表示を前提としない。既存の情報密度ルールを適用する。

## 初期照明史 LOCK：太陽光から火へ
### 太陽光
- 紀元前5世紀頃の古代ギリシャ劇場を、自然光（太陽光）による舞台照明の代表例として扱う。
- 最初期は照明を人が操作するのではなく、太陽・天空光・時間経過など自然環境そのものが舞台の光を決めていた。
- 「先生のひとこと」は既存LOCK文を使用する。

### 火・松明・かがり火
- 太陽光の次の大きな段階として、「炎を人が用意できる光として使う」を採用する。
- 松明・かがり火は、史料確認なしに特定の劇場・年代・用途へ断定して配置しない。
- 「火」「松明」「かがり火」を別イベントにするか、代表例として一項目にまとめるかは、史料の裏付けを確認して最終確定する。
- 16世紀イタリア宮廷劇に見られる、人工光を配置・明暗・消灯などで演出へ利用する段階とは区別する。

## 16〜17世紀の扱い LOCK
- この時代は、人工光源だけでなく劇場・舞台環境そのものの変化を同時に追う重要ゾーンとする。
- 地域や劇場形式によって自然光中心の野外上演と人工光を利用する屋内上演が並行していたことを前提にし、世界全体が一斉に屋内化したようには表現しない。
- 16世紀イタリア宮廷劇で確認できる「舞台と客席の明暗差」「光量差」「色の利用」「場面に応じた消灯・遮光」などは、「光を演出として扱う」重要資料として採用する。
- Shakespeare期の英国では、Globeのような昼光中心の屋外劇場と、Blackfriarsのような屋内劇場が並行していたことを、劇場・舞台環境LINEとの関係で扱う。


## 比較史表示ルール LOCK
- Historyは単一地域の一本道の技術史にしない。同時代の異なる地域・文化圏を比較できる構成とする。
- 横方向は時間軸とし、横に追うことで時代による変化を見る。
- 縦方向は同時代比較の軸とし、同じ年代位置で地域・劇場環境・技術を縦に比較できるようにする。
- 例として、15〜16世紀前後の日本の能舞台と英国の開放型劇場など、直接の影響関係を前提とせず、離れた地域がそれぞれの環境・利用可能な技術の中でどのような解決へ至ったかを比較して見せる。
- 類似した形式や技術が存在しても、史料上の交流・伝播が確認できない限り「同じ思想」「影響を受けた」などの因果関係は付与しない。
- 比較による解釈と、史料で確認できる歴史的事実は明確に区別する。
